## What it does

The application helps users track their daily moods, interact with an AI-powered chatbot that responds based on their emotional state, and provides personalized mental wellness content. Built with a mobile-first approach.

## What I built

<Features>
<Feature name="Mood tracking">Multi-step form with state persistence across pages using React Context API. Mood data is stored with timestamps for pattern analysis.</Feature>
<Feature name="AI chatbot">OpenAI API with system prompts that adjust to the mood the user entered.</Feature>
<Feature name="Authentication and privacy">Arctic Auth; mood data and journal entries are private and linked to user accounts.</Feature>
<Feature name="Multi-page form">Mood input, journaling and recap are kept in one state and sent as a single POST request.</Feature>
</Features>

## What was hard

<Problems>
<Problem problem="Keeping form state across pages and posting only at the end.">React Context stores every step; one final function combines it into a single POST.</Problem>
<Problem problem="A chatbot that remembers the mood the user entered.">Dynamic system prompts that include the mood data in every API call.</Problem>
<Problem problem="Slow AI responses, especially on mobile.">Streaming responses, typing indicators, and server components where they help.</Problem>
<Problem problem="A team of four with full-time jobs and little time.">MoSCoW prioritisation, a sprint plan with clear owners, async daily standups.</Problem>
</Problems>
