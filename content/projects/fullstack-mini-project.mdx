## Animal Quiz Game

<YouTube id="JzLHpBjw8Jo" title="Animal Quiz Game demo" />

A fast-paced animal quiz game built with vanilla JavaScript and Tailwind CSS, challenging players with true/false questions fetched from the Open Trivia DB API.

Features include real-time scoring, a lives system, and a countdown timer for each question – making it not just a test of knowledge, but also quick thinking.

This project was my playground for mastering API integration, error handling, and responsive design implementation in a real-world scenario.

*Tech stack: JavaScript, HTML, Tailwind CSS, Open Trivia DB API*

## Barang X Lupa

<YouTube id="fFXYv6oge4A" title="Barang X Lupa demo" />

A Next.js-powered solution born from those "oh no, it's moldy!" moments we've all had. Built with *React*, *HeroUI*, and *AppBackend.io*, this app keeps track of your groceries and their expiration dates, sending timely alerts before your food goes bad.

What started as a simple "I should remember what's in my kitchen" problem turned into a practical implementation of real-time data management, featuring CRUD operations, date formatting, and state management using React's useState and useEffect hooks. The best part? It's already prevented countless items from becoming rotten stinky vegetables and fruits on my fridge (yup, i personally used this apps)

*Tech highlights: Next.js, React, HeroUI, AppBackend.io integration, React Hooks (useState, useEffect), API integration, error handling, real-time expiry alerts, and responsive design.*
